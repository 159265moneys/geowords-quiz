# GeoWords — ジオゲのことば

[クイズを開く](https://159265moneys.github.io/geowords-quiz/)

街の看板で見かける単語から言語または日本語の意味を選ぶ、4択クイズ。40言語・110問を収録しています。

- 言語・意味の2モード切り替え（切り替えると新しいクイズを開始）
- 10問・25問・110問のランダム出題
- 回答後に日本語の意味、綴りの見分け方、用法、言語の系統・歴史を表示
- 文字・綴り・標識の文脈でどこまで絞れるかを正解欄に表示
- 単語ごとの辞書リンクと、言語・地域の参考資料
- 正答数・連続正解・結果表示・間違えた問題だけの復習
- スマートフォン、キーボード（1〜4・Enter）、右から左の文字に対応

## 収録方針

2026-10-06時点で、GeoGuessrの通常の道路カバレッジで役立つ国・地域の基本的な看板語を選定しました。道路・薬局・商店・学校・役場・出口などを中心とした教材であり、出現頻度を計測したランキングではありません。全言語・全出題地域を網羅するものではありません。特定のカスタムマップや、将来の対戦用マップの採用国を保証するものでもありません。

複数言語で同じ綴りを使う場合、該当言語を誤答候補から外します。同形の活用形や別義の語も保守的に除外しています。看板の一語だけで国を特定できない場合は解説で示し、文字体系・言語・国を混同しないようにしています。DUR・BERHENTI などは「通常の道路カバレッジの停止標識」という条件を含めて強い国判定の手がかりとし、無条件の100%判定は表示しません。

問題に出す文字は学習用に組んだ表示で、実際の道路標識の写真・配色・形状を再現するものではありません。GeoGuessrの非公式学習サイトです。

## ローカル実行

Node.jsとPython 3がある環境で実行します。実行時のnpm依存パッケージはありません。

```sh
npm start
```

`http://127.0.0.1:4173` を開きます。静的なES Modulesを使うため、ファイルを直接開かずHTTPサーバーを使用してください。

```sh
npm test
```

テストは、110問の整合性・曖昧な選択肢の排除・全問到達・二重回答防止・採点・復習を確認します。

## ファイル

- `data.js`: 問題、解説、言語プロフィール、出典
- `recognition.js`: 各語の識別の強さ・条件・例外
- `quiz.js`: 出題・選択肢・採点のロジック
- `app.js`: 画面表示と操作
- `styles.css`: レスポンシブデザイン
- `SOURCES.md`: 参考資料と各問題の出典
- `scripts/quiz.test.mjs`: ロジックと教材の整合性テスト

問題の追加・変更時には、意味・対象言語・同綴りの他言語・出典を確認してからテストを実行してください。

## GitHub Pages

`main` ブランチのルートを公開元に設定しています。ビルドは不要です。`.nojekyll` でJekyllの処理を無効化しています。公開対象に認証情報や調査用キャッシュを含めないでください。

回答・スコアはタブ内のメモリのみで保持され、リロードするとリセットされます。分析ツールやサーバーへの回答送信はありません。フォントはGoogle Fontsから読み込み、読み込めない場合は端末のフォントへフォールバックします。
