# GeoWords — 国までたどる模範解答集

[模範解答集を開く](https://159265moneys.github.io/geowords-quiz/) · [練習クイズ](https://159265moneys.github.io/geowords-quiz/quiz.html)

移動ありのGeoGuessrで、観察したものから候補を絞り、足りない証拠を探しに進むための教材です。

- **7つの観察手順**：太陽 → 建築・植生 → 道路 → 電柱 → 標識 → ナンバー → 文字
- **205枚の観察カード**：見えた特徴・絞れる範囲・次に見るものを条件の組み合わせで表示
- **200本の模範ルート**：観察 → 残る候補 → 決め手 → 国、または地域で保留
- **6つの行き詰まりへの対応**：自然だけ、通行方向不明、判読不能、一台だけ、矛盾、時間切れ
- 国・特徴で検索、地域・観察項目で絞り込み。「国まで」「その辺で止める」を切り替え。24件ずつ表示
- 実写42枚・生成参考7枚。ナンバー16枚は番号・国名コードをモザイク加工し、地色・帯・形で比較。タップで拡大

## 練習クイズ

- 国の条件セット80問／言語／意味の3モード（切り替えると新しいラウンド）
- 単語は40言語・110問。基本30語／全110語を切り替え
- 10問・25問・選んだ教材の全問をランダム出題（教材より多い問数は非表示）
- 言語の正解欄に国・地域、意味、見分け方、用法、系統・歴史を表示
- 国の問題は観察事実のみを出題し、言語名・推論・比較・写真の出典は回答後に表示。拡大画像のタイトル・代替テキストも出題用ラベルを使用
- 回答後は条件の組み合わせ・似た国との違い・適用条件・次の移動を表示
- 正答数・連続正解・結果表示・間違えた問題だけの復習
- スマートフォン、キーボード（1〜4・Enter）、右から左の文字に対応

## 教材の考え方

「国まで」は、示した地域・道路カバレッジ・観察条件がそろう場合の実用的な判定です。無条件の100%や実測の90%を意味しません。太陽、似た植生、共通の道路線だけでは国を強制的に決めず、候補を広く残します。南部アフリカの線やレソト周辺の高地は、あえて地域で止める模範例にしました。

ナンバーは登録国の手がかりです。普通車を複数確認し、固定された現地の道路表示と組み合わせます。商用車、外国車、旧式、撮影年代を区別します。ポルトガルの黄色い右帯やガーナの黒テープなど、「あるときに使える」特徴の不在を除外理由にはしません。

移動ありでは交差点、町の入口、役所・学校の住所、標識の裏へ進みます。同じ弱い証拠を繰り返し集めず、別の種類の証拠へ切り替えます。国が分かった後は、地名＋道路番号＋方角を地図と照合します。情報のない場面では国を必ず特定できるとは限りません。本教材は全出題国・全場面の網羅や自動判定器ではありません。

2026-10-07時点で、通常の道路カバレッジで役立つ条件を選定しました。採用国や出題率はマップに依存します。ルクセンブルクの出題率を固定の数値にはしていません。国の所属・国境の判断は文字一つでは行いません。

語彙は街路名、標識、薬局、商店、学校、役所、出口などを中心に選んでいます。複数言語で共有する綴りは誤答候補から外しますが、辞書に別義の同形語があるだけで実戦の価値を否定しません。基本30語は編集上の入門セットです。

写真の作者・出典・ライセンス・加工内容、生成参考画像のプロンプトは [PHOTO_CREDITS.md](PHOTO_CREDITS.md) に記録しています。画像にも実写／生成参考のバッジを付け、拡大画面から出典を開けます。番号が読めるナンバー原本は公開フォルダーに含めず、拡大時も同じ加工済み画像を使います。スイスの前後写真は別縮尺、スリランカの前後は異なる車両の色の例です。太陽の参考写真だけでは方位・半球は判定できません。

地理・語義・由来の参考資料は [SOURCES.md](SOURCES.md) と画面内の資料リンクにまとめています。GeoGuessrの非公式学習サイトです。

## ローカル実行・検証

Node.jsとPython 3を使用します。実行時のnpm依存パッケージはありません。

```sh
npm start
```

`http://127.0.0.1:4173` を開きます。静的なES Modulesを使うため、ファイルを直接開かずHTTPサーバーを使用してください。

```sh
npm test
```

19件のテストで、語彙と国の選択肢、全問到達、採点、二重回答防止、復習、観察手順から各ルートへの参照、地域での保留、読み込みバージョンを確認します。

2026-10-07の拡張では、Chromiumで205カードの到達、全200ルートの開閉、ページ送り、地域・観察項目・検索の併用、国80問の採点と40問の復習対象を確認。回答前後の写真拡大、全49画像のデコード、幅390pxの表示、言語・意味モードへの切り替えも確認しました。

## 主なファイル

- `index.html`, `guide.js`, `guide.css`：模範解答集の画面・検索・手順の切り替え
- `guide-data.js`：観察手順、模範ルート、移動先、資料
- `quiz.html`, `app.js`, `quiz.js`：クイズ画面・進行・採点
- `country-cases.js`：54の国・地域に各3つの追加ケース（道路・別の分岐・現地住所）
- `country-data.js`, `country-ui.js`：国の条件セット・写真・比較
- `data.js`, `recognition.js`, `courses.js`：語彙・言語・見分け方・コース
- `styles.css`：共通の表示とクイズのデザイン
- `SOURCES.md`：参考資料と各語の出典
- `scripts/*.test.mjs`：教材の整合性とロジックのテスト

## GitHub Pages

`main` ブランチのルートを公開元に設定しています。ビルド不要、`.nojekyll` でJekyll処理を無効にしています。調査用キャッシュや認証情報は公開しません。

回答・スコアはタブ内のメモリにのみ保持され、リロードでリセットされます。分析ツールやサーバーへの回答送信はありません。フォントはGoogle Fontsから読み込み、失敗時には端末のフォントへフォールバックします。

更新時はHTMLとES Modulesの読み込みURLのバージョンをそろえて更新します。
